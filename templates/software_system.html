What It Is

AI-Assisted ICU Quality Review Workbench

The software system is a Flask-based ICU stay review prototype. It combines a dashboard, searchable case library, case safety profile screen, trained supervised AI risk prediction model, explainable AI output, optional summary assistant, local review notes, and review history / audit trail.

AI Features

Included AI Components

ML

AI Risk Prediction

Loads the trained supervised model and estimates risk probability for each ICU stay.

XAI

Explainable AI

Displays top model signals and separates missing feature warnings from present feature values.

GEN

Review Summary Assistant

Uses live LLM mode only when configured or a template-based offline summary otherwise.

Download / Run

Run The Software System Locally

git clone <repo-url>
cd Software_System
python -m venv .venv
source .venv/Scripts/activate
pip install -r requirements.txt
python app.py

Git Bash / direct virtualenv alternative

./.venv/Scripts/python.exe app.py
Use Workflow

How To Use The Software System

  1. Open the Dashboard to view case counts and active queue work.
  2. Open the Case Library and filter or search cases.
  3. Open a Case Safety Profile.
  4. Review AI risk, SIRS-style screening, supporting analytics, and the review-support summary.
  5. Save review documentation and inspect the audit trail.
