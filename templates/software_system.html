What It Is

AI-Assisted ICU Risk Review System

The software system is a Flask-based ICU stay review prototype. It combines a dashboard, searchable case worklist, detailed assessment screen, trained supervised AI risk prediction model, explainable AI output, interactive AI assistant, local review notes, and review history / audit trail.

AI Features

Included AI Components

ML

AI Risk Prediction

Loads the trained supervised model and estimates risk probability for each ICU stay.

XAI

Explainable AI

Displays top model signals and separates missing feature warnings from present feature values.

GEN

Interactive AI Assistant

Answers case-review questions using live LLM mode when configured or offline fallback mode otherwise.

Download / Run

Run The Software System Locally

git clone <repo-url>
cd icu-risk-workflow
python -m venv .venv
source .venv/Scripts/activate
pip install -r requirements.txt
python app.py

Git Bash / direct virtualenv alternative

./.venv/Scripts/python.exe app.py
Use Workflow

How To Use The Software System

  1. Open the Software Home page.
  2. Open the ICU Dashboard to view case counts and priority queue.
  3. Open the ICU Case Worklist and filter cases.
  4. Open an ICU Stay Assessment page.
  5. Review baseline, multi-agent, AI prediction, explainability, and generated summary sections.
  6. Ask the Interactive AI Assistant review-support questions.
  7. Save review documentation and inspect the audit trail.
