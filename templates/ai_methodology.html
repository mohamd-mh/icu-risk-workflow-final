Generative Support Layer

Generative AI Assistant

The ICU case assessment page includes an interactive assistant for case review questions. If LLM_API_KEY is configured in the environment, the assistant can call a real external LLM API through the isolated agents/generative_ai_agent.py module.

If no API key is configured, the assistant uses an offline fallback that generates structured summaries and explanations from the case data, AI prediction, explainability output, data quality, baseline result, and workflow trace.

The assistant generates review-support summaries and explanations. It does not make medical decisions and does not provide diagnosis, medication, treatment, or clinical instructions.

This is an academic clinical decision-support prototype for explanation, comparison, and review documentation. It is not a clinical deployment.
