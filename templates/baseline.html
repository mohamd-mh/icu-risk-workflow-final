Baseline Pipeline

The baseline pipeline is a simple single-pipeline unweighted rule-based workflow. It uses one direct path from ICU stay features to a risk result and a basic explanation.

Patient features Risk calculation Low / medium / high risk Basic explanation

This approach is useful as a comparison point because it is simple and easy to understand. It is compared with the planning-driven multi-agent workflow in the Results & Comparison page.

The baseline uses threshold rules for age, admission type, vital signs, oxygen saturation, and lab values. Each abnormal condition adds one risk point, so the method stays easy to inspect.
