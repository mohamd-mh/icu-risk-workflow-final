Interpretation

Precision / Recall Tradeoff

Accuracy alone is not enough because the hospital mortality label is imbalanced. Precision, recall, F1, and the confusion matrix should be read together.

The workflow contribution is transparency, traceability, documentation, auditability, and review context. The modular workflow should not be described as improving mortality prediction unless future metrics clearly demonstrate that claim.

Limitations

Academic Prototype Limits

  • Evaluation is based on a processed academic MIMIC-III feature table, not a live hospital deployment.
  • The target label is used only for training/evaluation and is excluded from model inputs.
  • The SIRS-style baseline is a transparent screening comparison, not diagnosis or mortality prediction.
  • Regenerating the processed dataset or retraining the model may change these metrics.
