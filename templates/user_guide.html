User Guide

AI-Assisted ICU Case Review System - User Guide

A simple manual for the Case Review Coordinator.

Open Review Queue

Who uses this system?

The Case Review Coordinator manages ICU case review tasks, prioritizes cases, adds notes, and tracks review progress.

What can the user do?

  • See which cases need review first.
  • Add dataset or manual cases to the queue.
  • Read the AI summary and advanced AI details.
  • Edit status, priority, and reviewer.
  • Add notes and view audit history.
  • Print case summaries.

Main workflow

  1. Open Review Queue.
  2. Add a dataset case or add a new manual case.
  3. Open the case review item.
  4. Read the AI Summary.
  5. Update status, priority, reviewer, and notes.
  6. Check the audit trail.

Review Queue

The queue shows cases waiting for review, follow-up, or documentation. Use filters for Status, Priority, Risk, and Search.

Add New Case

Enter basic information, vital signs, and lab values. Select Run AI Analysis to create an AI-supported review item.

Case Library

The Case Library contains the included processed ICU cases. Open a case or add it to the Review Queue.

Reading the AI Summary

The AI Summary shows risk level, probability, confidence, key explanation features, and data quality warnings.

Advanced AI Details

Advanced details include similar cases, cluster context, anomaly detection, uncertainty details, explainability table, and baseline comparison. These are generated from real ML/data algorithms and are provided for transparency.

Notes and Audit Trail

Notes and status changes are saved locally. Audit events show what changed and when.

Safety limits

This academic prototype supports case review and documentation only. It does not provide diagnosis, medication, or treatment recommendations.
