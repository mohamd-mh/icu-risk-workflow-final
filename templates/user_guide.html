User Manual

AI-Assisted ICU Quality Review System

A practical guide for completing the review workflow.

Open Quality Review Queue

What the system does

It combines ICU case tracking, AI-supported review summaries, documentation, follow-up status, and audit history in one local workflow.

Who uses it?

The ICU Quality & Patient Safety Coordinator manages review prioritization, follow-up, notes, status, and audit history. The user does not diagnose patients or choose treatments.

How to run it

cd C:\projects\Final_Project_Clean\Software_System
C:\projects\icu-risk-workflow\.venv\Scripts\python.exe app.py

Open http://127.0.0.1:5000/.

Main workflow

  1. Open the Quality Review Queue.
  2. Open an existing case or add a new one.
  3. Read the AI Summary.
  4. Set priority and status.
  5. Add a coordinator note.
  6. Check the audit trail.
  7. Open Advanced AI Details only when more context is needed.

Quality Review Queue

The main work page shows cases waiting for review, follow-up, or documentation. Search and filter by status, priority, or AI risk, then open a review item, add a note, or archive it.

Add New Case

Enter available basic context, vital signs, and laboratory values. Missing inputs are handled by the model pipeline. Run AI Review Analysis to create and open a review item.

Case Library

Find a processed ICU case, open its assessment, or add it to the Quality Review Queue.

Reading the AI Summary

The supervised ML model produces a probability mapped to Low, Medium, or High review-support risk. Confidence, top model signals, and data-quality notes help the coordinator prioritize review; no individual input manually determines risk.

Advanced AI Details

When needed, inspect explainability, KNN similar cases, KMeans cluster context, IsolationForest anomaly detection, uncertainty, and the baseline-versus-modular workflow comparison. The AI Model Report explains processing, features, methods, metrics, and related work.

Notes and Audit Trail

Save coordinator notes with status and priority. The audit trail records review changes for follow-up and traceability.

What the system does not do

It does not diagnose, prescribe, recommend treatment, or replace qualified clinical staff. Its outputs support quality review and documentation only.
