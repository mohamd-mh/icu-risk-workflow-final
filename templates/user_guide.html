User Guide

AI-Assisted ICU Quality Review Workbench

Workflow guide for the ICU Quality & Patient Safety Coordinator.

Start Next Review

Who Uses This Workbench

The target user is an ICU Quality & Patient Safety Coordinator who reviews prioritized cases, documents local review notes, prepares a structured summary, and marks the ticket ready for the Quality & Patient Safety Review Team.

Coordinator Workflow

Coordinator Workflow

  1. Open Dashboard
  2. Click Start Next Review
  3. Review AI Review Guide
  4. Open/Create Review Ticket
  5. Complete Guided Review Checklist
  6. Add Coordinator Note
  7. Generate Prepared Review Summary
  8. Mark Ready for Quality Team Review
  9. Continue to next case

What AI Helps With

AI sorts the work by estimating risk probability, assigning a risk tier, showing SIRS-style screening context, surfacing model signals, and identifying missing or uncertain data that the coordinator should document.

What The System Does Not Do

{{ safety_sentence }}

  • It is not a live hospital EHR.
  • It is not real-time ICU monitoring.
  • It does not provide care-plan or medication advice.
  • It does not replace the Quality & Patient Safety Review Team.

What Gets Prepared

The Review Ticket prepares a concise handoff summary for the Quality & Patient Safety Review Team. The summary includes the case reference, reason flagged, AI risk and probability, SIRS screening, main model signals, data quality or uncertainty notes, coordinator note summary, current priority/status, and recommended next review step.

Dashboard

The Dashboard is the starting point. Use Start Next Review to open the highest-priority active ticket, or use Top Cases Needing Attention to open a profile or create a ticket.

Case Safety Profile

The Case Safety Profile explains why a case matters. Start with the AI Review Guide, then review the risk tier, probability, SIRS screening, confidence/data quality, model signals, and any missing or uncertain data.

Review Ticket

The Review Ticket is the main work page. Use the Guided Review Checklist, add a coordinator note, generate the Prepared Review Summary, set priority/status, and mark the ticket Ready for Quality Team Review when the handoff material is ready.

Create Review Ticket

Use Create Review Ticket for a local manual case that is not already selected from the Case Library. Empty numeric fields are allowed; invalid numeric text shows a field error instead of a server error.

Review Queue

The Review Queue shows new work, in-review tickets, follow-up items, tickets ready for the quality team, reviewed cases, and archived tickets. Filters help coordinators focus on status, priority, AI risk, SIRS screening, source, and owner.

Installation / Running Instructions

From the parent project folder, enter the software folder, create a virtual environment named .venv, install dependencies, then start the app.

PowerShell:

cd Software_System
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python app.py

Git Bash:

cd Software_System
python -m venv .venv
source .venv/Scripts/activate
pip install -r requirements.txt
python app.py

Open http://127.0.0.1:5000/.
