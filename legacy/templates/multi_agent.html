Multi-Agent Workflow

The planning-driven multi-agent workflow divides the risk assessment process into smaller roles. It starts from the baseline risk estimate, then checks data quality, calculates a weighted clinical verification score, verifies consistency, explains the result, and records a workflow trace.

Agent Roles

  • Planner Agent: decides the steps needed for the patient case.
  • Data Validator Agent: checks missing or unusual feature values.
  • Weighted Risk Assessor Agent: calculates a weighted clinical score.
  • Verifier Agent: checks consistency and uncertainty.
  • Explainer Agent: writes a clear explanation for the result.
  • Trace Agent: records the workflow steps for transparency.

Connection to LPW and AutoGen

LPW inspired the planning and verification structure. AutoGen inspired the division into specialized agents with clear responsibilities.

This is a Software Engineering prototype inspired by those papers, not an operational AutoGen integration or live LLM API system. The main advantage is reliability, transparency, modularity, and traceability.
