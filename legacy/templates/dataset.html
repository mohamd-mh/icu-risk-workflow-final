Dataset

The project uses a real extracted subset of MIMIC-III, a public critical care database. When available, the application and AI training pipeline use data/patient_features_ai.csv, an expanded prepared feature file with 1000 ICU stays. If that file is unavailable, the app falls back to data/patient_features.csv.

Relevant MIMIC-III files for this project include:

  • PATIENTS.csv
  • ADMISSIONS.csv
  • ICUSTAYS.csv
  • CHARTEVENTS.csv
  • LABEVENTS.csv
  • D_ITEMS.csv
  • D_LABITEMS.csv

CHARTEVENTS.csv is too large to load directly in this simple Flask website. Because of that, preprocessing creates smaller feature files that are easier to display and evaluate.

Raw MIMIC-III files are not included in this repository.

Generated Files

  • data/patient_features.csv: current feature file used by the website.
  • data/patient_features_real.csv: real extracted MIMIC-III feature output.
  • data/feature_availability_report.csv: feature completeness report.
