# Preprocessing Documentation

This folder documents the preprocessing workflow for the academic ICU Quality
Review Workbench. Raw MIMIC-III files are not included in this repository.

## Runtime Dataset

- `data/patient_features_ai.csv` is the final processed dataset used by the
  Flask app and saved AI model at runtime.
- It contains 1000 ICU-stay records.
- `data/patient_features_real.csv` was an earlier 100-row processed output used
  during development, but it is not the final runtime dataset.
- The app does not read raw MIMIC tables during normal use.

## Source Tables

The processed feature table was derived from the course-provided full
MIMIC-III v1.4 dataset. Expected source files:

- `PATIENTS.csv`
- `ADMISSIONS.csv`
- `ICUSTAYS.csv`
- `D_ITEMS.csv`
- `D_LABITEMS.csv`
- `CHARTEVENTS.csv`
- `LABEVENTS.csv`

Large event tables such as `CHARTEVENTS.csv` and `LABEVENTS.csv` must be read
in chunks. `CHARTEVENTS.csv` can be tens of gigabytes and should never be
copied into this repository.

## Reproducibility Notes

- The original extraction implementation is not included in this submission
  package.
- `check_mimic_files.py` can verify that a local raw-data directory contains
  the expected MIMIC files.
- `build_features.py` is a guarded placeholder documenting the required inputs
  and output-safety rules. It does not silently regenerate or overwrite the
  included processed dataset.
- Regenerating `patient_features_ai.csv` may change model metrics and requires
  retraining and retesting the AI model.

## Safety Rules

- Do not commit raw MIMIC files.
- Do not commit `.venv`, `__pycache__`, logs, `.env`, SQLite databases, or
  generated bytecode.
- Do not overwrite `data/patient_features_ai.csv` unless the project team has
  explicitly decided to regenerate the model and validation artifacts.
